# Wallpapers and Coloring Pages Resource

This repository contains the source code for a lightweight, static **GitHub Pages site** focused on digital art appreciation and educational content.

You can view the live site here:  
👉 **https://sharjeel2025.github.io/art-resources/**

### Site Structure
The project includes five clean, single-purpose HTML pages:

- `index.html` → Homepage and central navigation hub  
- `anime-wallpapers.html` → Insights into anime art styles, resolutions, and desktop/phone optimization  
- `stitch-wallpapers.html` → Overview of Stitch character aesthetics, emotional designs, and popularity  
- `dark-souls-wallpapers.html` → Exploration of dark fantasy visuals and atmospheric game-inspired art  
- `coloring-pages.html` → Discussion of the relaxation and cognitive benefits of printable coloring activities  

### Purpose
The content is purely informational and beginner-friendly. It aims to help enthusiasts better understand:
- Technical aspects of digital wallpapers (resolutions, aspect ratios, device compatibility)  
- Aesthetic trends in anime, character art (Stitch), and dark fantasy (Dark Souls)  
- Creative and therapeutic value of coloring pages  

No downloads or heavy assets — just concise, educational explanations.

### Deployment Instructions
To run your own copy or fork this project:

1. Create a new GitHub repository  
2. Upload the HTML files to the root directory  
3. Go to **Settings → Pages**  
4. Set source to **main** branch (or gh-pages if you prefer)  
5. Save → your site will be live at `https://yourusername.github.io/your-repo-name/`
